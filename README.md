# Nadis_Greeting

Анімована книжка-привітання з Днем народження для Надії (від асистента Влада).

- `index.html` — сторінки книжки: обкладинка, офіційне привітання, неформальне привітання, побажання, задня обкладинка.
- `style.css` — мінімалістичний стиль у м’яких фіолетово-синіх тонах.
- `script.js` — перегортання сторінок (клік, свайп, стрілки ←/→, кнопки).
- `assets/` — стиснені фото для сторінки (оригінали лежать у `photo/`).

Відкрийте `index.html` у браузері або увімкніть GitHub Pages для цієї гілки.
На телефоні книжка показує по одній сторінці, на комп’ютері — розворот.
